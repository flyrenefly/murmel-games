# Soundeffekte aus Enigma

Diese Klänge stammen aus dem freien Spiel **Enigma**
(https://github.com/Enigma-Game/Enigma, Stand 6f0c51b2, `data/soundsets/enigma`).
Sie wurden mit `tools/convert-sounds.mjs` unverändert in 16-Bit-PCM-WAV
umgewandelt (Browser spielen das ursprüngliche MS-ADPCM nicht ab).

Herkunft laut Enigma (`ENIGMA-SOUNDS-README.txt`):

| Datei | Herkunft |
|---|---|
| shatter.wav | AfterStep |
| st-oxydopened.wav | xboing |
| menuok.wav | xlogical |
| st-move.wav | lbreakout2 (GPL) |
| st-stone.wav, st-oxydopen.wav, menumove.wav, ballcollision.wav, st-switch.wav, st-metal.wav, it-triggerdown.wav, it-triggerup.wav, pickup.wav | nach bestem Wissen des Enigma-Teams gemeinfrei |

Enigma verteilt diese Dateien als Teil seines GPL-Pakets; Murmel übernimmt sie
mit dieser Quellenangabe.
