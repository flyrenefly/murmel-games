# Grafiken aus Enigma

Die Bilder in diesem Ordner stammen aus dem freien Spiel **Enigma**
(https://github.com/Enigma-Game/Enigma, Stand 6f0c51b2, Ordner `data/gfx32`
und `data/gfx32-retro`). Enigma steht unter der GNU General Public License,
Version 2 oder (nach Wahl) jeder späteren Version; Text siehe
`COPYING-GPL-2.0.txt`. Urheber: das Enigma-Team, Grafiken überwiegend von
Daniel Heck. Die Retro-Fassungen wurden laut Enigma-Verlauf durch Anwenden
von Farbpaletten auf die Originalgrafiken erzeugt.

Murmel nutzt sie unverändert unter GPL-3.0-or-later (kompatibel mit
„GPL v2 or later“).
